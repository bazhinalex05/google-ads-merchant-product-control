# Unified Merchant Product Control: короткая инструкция по установке для опытных

1. Перед настройкой проверьте, какие два custom label свободны для записи Funnel Stage и Priority Group и не конфликтуют с действующими правилами клиента.
2. Там же, в настройках основного фида, проверьте и запомните время его обновления: обновление допфида нужно будет настроить на час раньше.
3. Создайте скрипт в Google Ads и вставьте актуальный код.
4. Создайте пустую Google-таблицу и укажите её ссылку в SPREADSHEET_URL.
5. Над редактором кода откройте «Расширенные API» и включите Merchant API: Products и Accounts. Сохраните и авторизуйте скрипт.
6. Выполните первый запуск для создания Settings. Остановка с запросом Merchant ID ожидаема.
7. Заполните Settings:
   - **Основні налаштування:** Merchant ID, общий Target CPA и маржа; неизвестные CPA и маржу оставьте пустыми.
   - **Фільтри фідів і Merchant API:** ID рабочих фидов; при необходимости — метка фида и язык.
   - **Увімкнення функцій:** для базового запуска оставьте значения по умолчанию.
   - **Етапи воронки:** источники benchmark и приоритета; два разных выходных custom label для Funnel Stage и Priority Group.
   - **Сезонність:** не меняйте до заполнения сезонов клиентом; затем выберите активные сезоны и включите фильтр.
   - **Категорії товарів:** альтернативный источник включайте только при необходимости.
   - **Карантин:** выберите правила, пороги, периоды проверки и сроки пауз.
   - **Службові налаштування скрипта:** не меняйте; reset_quarantine оставьте выключенным.
8. Запустите скрипт повторно для создания остальных рабочих листов.
9. На ProductTypes согласуйте с клиентом и отметьте рекламируемые категории. Задайте общую сезонность категорий, индивидуальные сезоны товаров — на Seasonality. Якщо Seasonality порожній, виберіть активні сезони, увімкніть сезонний фільтр і запустіть скрипт для заповнення листа. Зміни сезонів застосовуються наступним запуском; при вимкненому фільтрі лист не перезаписується.
10. При необходимости уточните на ProductTypes Target CPA, маржу, benchmark и приоритеты категорий. Список «ID — приоритет» внесите на Priorities, если он нужен.
11. Повторно запустите скрипт и проверьте Products, ProductDiagnostics, QuarantineRegistry и дашборды.
12. Проверьте отсутствие конфликтов выходных custom label с правилами клиента. При конфликте измените выходные поля в Settings и повторите запуск.
13. Только после проверки подключите таблицу в Merchant Center как допфид к нужному основному источнику. Products должен быть первым листом.
14. После обработки убедитесь, что метки и исключения у выбранных ID в Merchant соответствуют допфиду.
15. По принятой схеме настройте ежедневное обновление допфида ровно за час до основного фида, в одном часовом поясе.
16. Установите ежечасный запуск скрипта в Google Ads.
