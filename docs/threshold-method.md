# Як обчислюються високі кліки та покази

Формула чинного коду не змінена. Вона послаблює вплив нулів, але не прибирає нулі з розрахунку.

```text
Статистика Ads за funnel_days_ago → ID вибраного Merchant-каталогу
    → товари без додатних конверсій → benchmark-групи
    → окремі пороги кліків і показів → етап товару
```

Період за замовчуванням — 14 днів включно сьогодні у часовому поясі Ads. Це не окремі 30-денні вікна правил карантину. База містить тільки рядки статистики, ID яких присутні у вибраному Merchant-каталозі; відсутні в статистиці товари штучно не додаються до бази нулів. Нульові метрики наявних рядків беруть участь. Товари з додатними конверсіями виключені з порогової бази та отримують «1 продажі» незалежно від порогів. Benchmark визначається чинними правилами категорії/атрибута, за відсутності — default_benchmark_group; групи не змішуються.

Для кожної метрики окремо:

- A = сума всіх значень / кількість усіх товарів бази, включно нулями.
- B = сума додатних значень / кількість додатних значень.
- T = ceil((A + B) / 2): округлення вгору до цілого.
- Для порожнього знаменника відповідне середнє = 0.
- Високий показник: одночасно x > A та x >= T, лише якщо існують принаймні два різні додатні значення. Якщо всі додатні однакові або їх немає, високий сегмент вимкнений.

Нехай p — частка нулів. За невід'ємних значень A = B × (1 − p), а поріг до округлення T₀ = B × (1 − p / 2). За незмінного B нулі знижують T₀ вдвічі слабше, ніж звичайне середнє A. За B=100 та p=30%: A=70, T₀=T=85. Це компенсація впливу нулів, а не їх виключення.

## Порівняння на однаковій вибірці

Для альтернативних середніх нижче «високий» означає x строго більше відповідного середнього. Для чинного методу використовуються точні умови коду, наведені вище. Решта значень — низькі.

| Вибірка однієї метрики | Нулі | A | B | T | Високі за A | Високі за B | Високі за чинним методом |
|---|---:|---:|---:|---:|---|---|---|
| 70,80,90,100,110,120,130 | 0% | 100 | 100 | 100 | 110,120,130 | 110,120,130 | 110,120,130 |
| 0,0,60,80,90,100,120,150 | 25% | 75 | 100 | 88 | 80,90,100,120,150 | 120,150 | 90,100,120,150 |
| 0,0,0,70,80,90,100,110,120,130 | 30% | 70 | 100 | 85 | 80,90,100,110,120,130 | 110,120,130 | 90,100,110,120,130 |
| 0,100,100 | 33,33% | 66,67 | 100 | 84 | 100,100 | немає | немає: додатні однакові |
| 0,0,0 | 100% | 0 | 0 | 0 | немає | немає | немає |

При A=70 і T=85 значення 85 уже високе, 84 — низьке. При A=T=100 значення 100 низьке через суворе x>A. Кліки та покази оцінюються незалежно: обидва високі → «2 вк+вп», тільки кліки → «3 вк+нп», тільки покази → «4 нк+вп», обидва низькі → «5 нк+нп». Нуль кліків і показів без продажів → «6 без стат».
